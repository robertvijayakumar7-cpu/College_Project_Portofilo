# Alvin Steve Saji — Portfolio

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. No build tools are required.

## Customize
- Update repository and live-demo URLs in `index.html` with your real project links.
- Replace the scenic image URLs in `style.css` if you want to use local images.
- Add your CV file and change the Download CV link to its filename.
- Edit the email, LinkedIn and GitHub URLs to your real profile URLs.

## Included interactions
- Scroll reveal animations using IntersectionObserver
- Gentle hero-image parallax on scroll
- Responsive mobile navigation
- Active navigation state
- Project controls and hover micro-interactions
- Reduced-motion accessibility support

The sunrise hero image is included locally in assets/hero-boy.png. Project photography and Google Fonts are loaded externally, so an internet connection is needed for those images and fonts.

Glassmorphism update: translucent frosted-glass panels, blue glass borders, luminous button effects, animated gradient name, and a local sunrise hero scene featuring a seated boy.
